# EXPERIMENT_INDEX — summary locations

This file is an index based on directory and file names, **not an assertion
about numerical results**. Inspect actual summary tables and configuration files.

- `paper_results_archive/mnist_experiments/publication_summary/`:
  publication comparison tables and aggregates.
- `paper_results_archive/mnist_experiments/publication_main/`:
  per-run summaries for the principal publication experiments.
- `paper_results_archive/mnist_experiments/publication_ablation/`:
  per-run summaries for ablations.
- `paper_results_archive/mnist_experiments/rms_screen/`:
  per-run summaries for RMS screening.
- `paper_results_archive/mnist_experiments/decision_mnist/`:
  per-run summaries for decision comparisons.
- `paper_results_archive/mnist_controls/`:
  control results and aggregate summaries.
- `paper_results_archive/mnist_controls_confirmation/`:
  confirmation and stability summary information.
- `runs/mnist_experiments/publication_summary/plots/`:
  selected existing publication figures.
- `results_pareto_validation_all/`:
  top-level Pareto/score-alignment summary tables and manifest files.

Not copied: raw `arrays.pt`, per-level trajectory JSONL, most per-candidate
metrics, uncompressed data and full image galleries. Preserve the source folder
and existing GitHub archive; regenerate/rehydrate from it if necessary.
